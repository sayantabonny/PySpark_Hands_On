# Input catalogue

All landing data is generated by `tools\datagen` (`python -m data_generator --profile small --out Input --clean`).
Every file is plain ASCII. The schema files below describe each source's location, format, columns and types,
keys and delivery pattern. They describe the contract; they do not describe data-quality problems in the files.

`--clean` regenerates only `landing\` and `testdata\`, so the schema files in this folder are kept.

## Source data (`landing\`)

| Source | Schema file | Path under `Input\landing\` | Format |
|---|---|---|---|
| Helpdesk ticket snapshots | [helpdesk_tickets.md](helpdesk_tickets.md) | `helpdesk\tickets\` | JSON Lines + control files |
| Call-centre calls | [callcenter_calls.md](callcenter_calls.md) | `callcenter\tickets\` | CSV |
| CRM customer snapshots | [crm_customers.md](crm_customers.md) | `crm\customers\` | CSV |
| CRM customer-profile change feed | [crm_customer_changes.md](crm_customer_changes.md) | `crm\customer_changes\` | JSON Lines |
| Product catalog | [product_catalog.md](product_catalog.md) | `reference\products\` | CSV |
| Agent roster | [agent_roster.md](agent_roster.md) | `reference\agents\` | CSV |
| Billing account map | [billing_account_map.md](billing_account_map.md) | `billing\account_map\` | CSV |

Shared conventions:
- Every source is partitioned into folders named `arrival_date=YYYY-MM-DD`, the UTC date the file was delivered.
- File names carry the delivery time. Use the file path as lineage (`_source_file`); you are never asked to parse tokens out of it.
- The dataset covers 2026-09-02 to 2026-09-15 (anchor date), with deliveries up to 2026-09-17.
