2. Stages Tab
3. SQL Tab
4. Executors Tab
5. Storage Tab
6. Environment Tab

The user must always answer:

- What happened?
- Why did it happen?
- Which stage caused it?
- Which task caused it?
- Was shuffle involved?
- How much data moved?
- Was memory sufficient?
