Primary Topics (streamlined 2026-11-21)
==========================================
Each item is a skill to demonstrate in code, not a function to memorize. The function names in brackets
show the scope; the exercise prompts list the functions you may need. Importance tags are unchanged
from the original list (archive: archive\2026-11-21_before_streamlining\Primary_Topics.txt).
IDs: C = core objective (treated as High), O<section>.<item> = operation skill.

Core Objectives (Importance: High)
  C01 Conditional data manipulation
  C02 Adding fields: primary / surrogate keys, file-name metadata, ingestion timestamps
  C03 Date and timestamp manipulation (parsing, time zones, arithmetic)
  C04 Deduplication and duplicate detection, incl. sorting and selective dropping
  C05 Accumulators (counters, sums, debugging metrics) and broadcast variables
  C06 Advanced window functions, incl. window + aggregation
  C07 Partition-level processing: foreachPartition, mapPartitions, toLocalIterator
  C08 Complex types: arrays, structs, maps, JSON (transform, map, array, create_map, to_json)
  C09 EDA, statistical profiling, cardinality and categorical profiling
  C10 Dirty data handling
  C11 Correlation and relationship analysis
  C12 Partitioning strategy
  C13 Join optimization strategies
  C14 Skew handling, incl. joins with and without simple salting
  C15 Pivot tables (cross-tabulation)
  C16 Year-over-year (YoY) and month-over-month (MoM) analysis
  C17 Gap / anti-join analysis


Operations
==========

1. DataFrame Basics - Importance: Low
  O01.1 Projecting columns [select, selectExpr, alias, drop]
  O01.2 Deriving and renaming columns [withColumn, withColumns, withColumnRenamed]
  O01.3 Filtering rows [filter / where]
  O01.4 distinct vs dropDuplicates(subset)

2. Joins - Importance: High
  O02.1 Choosing the join type [inner, left, right, full outer, cross]
  O02.2 Semi and anti joins (existence and gap checks)
  O02.3 Multi-column, expression and range joins (incl. point-in-time / as-of)
  O02.4 Null keys in joins and null-safe equality [<=>, eqNullSafe]
  O02.5 Join cardinality and fan-out (duplicate keys)
  O02.6 Broadcast joins and join hints
  O02.7 Skewed joins (detect, then mitigate)

3. Aggregations & Grouping - Importance: Medium
  O03.1 groupBy / agg with multiple aggregates [sum, count, avg, min, max]
  O03.2 Distinct counting [countDistinct vs approx_count_distinct]
  O03.3 Collecting values [collect_list vs collect_set: order and dedup semantics]
  O03.4 Conditional aggregation [sum(when ...), count_if, filter]
  O03.5 Aggregation + join (aggregate before or after the join; grain)
  O03.6 Aggregation + window (aggregates over a window)

4. Window Functions - Importance: Very High
  O04.1 Window specs: partitionBy / orderBy
  O04.2 Ranking and tie semantics [row_number, rank, dense_rank]
  O04.3 Previous / next record comparison [lag, lead]
  O04.4 first / last (incl. ignoreNulls)
  O04.5 Frames: rowsBetween vs rangeBetween, and the default-frame gotcha
  O04.6 Running, cumulative and rolling calculations
  O04.7 Sessionization and gap detection
  O04.8 Event sequence analysis
  O04.9 Window + conditional logic; several window specs in one query
  O04.10 Latest-record selection and deduplication with windows

5. Deduplication - Importance: Medium
  O05.1 Exact vs key-based dedup [distinct, dropDuplicates]
  O05.2 Latest / earliest record per key, by timestamp [window, max_by / min_by]
  O05.3 Deterministic tie-breaking
  O05.4 Dedup before vs after a join

6. Conditional Logic - Importance: High
  O06.1 when / otherwise chains (first-match semantics, nesting)
  O06.2 Conditional logic with nulls [coalesce, null-safe tests]
  O06.3 Conditional logic inside aggregations, windows, joins and date logic

7. Null Handling - Importance: Medium
  O07.1 Null tests and three-valued logic [isNull, isNotNull, comparisons with null]
  O07.2 Null vs NaN [isnan]
  O07.3 Filling and dropping [fillna / na.fill, dropna / na.drop, coalesce]
  O07.4 Nulls in joins, aggregations, windows and sorting

8. Date & Time - Importance: Medium
  O08.1 Parsing strings to date / timestamp, incl. multiple formats [to_date, to_timestamp, try_to_timestamp]
  O08.2 Formatting and extracting parts [date_format, year, month, dayofweek, hour ...]
  O08.3 Date and timestamp arithmetic and differences [date_add, add_months, datediff, months_between, intervals]
  O08.4 Epoch conversions [unix_timestamp, from_unixtime, timestamp_millis]
  O08.5 Time zones (session time zone vs stored UTC instant) [from_utc_timestamp, to_utc_timestamp]
  O08.6 Truncating and bucketing time for period analysis [date_trunc, trunc]

9. String Operations - Importance: Low
  O09.1 Cleaning and normalizing [trim, lower / upper, regexp_replace, replace]
  O09.2 Parsing and extracting [substring, split, regexp_extract, length]
  O09.3 Building strings [concat, concat_ws]
  O09.4 Pattern matching [like, rlike, contains, startswith, endswith]

10. Arrays / Structs / Nested Data - Importance: Medium
  O10.1 Struct and nested field access [dot paths, select("s.*")]
  O10.2 Exploding and row cardinality [explode, explode_outer, posexplode]
  O10.3 Array functions [size, array_contains, element_at, slice, flatten, array_distinct]

  O10.7 JSON strings [from_json, to_json, schema_of_json]

11. Pivot / Unpivot - Importance: High
